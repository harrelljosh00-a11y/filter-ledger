# Brand Guidelines: Filter Ledger

## Name and positioning
- **Name:** Filter Ledger. A ledger is a record of evidence, which is exactly what we keep for every product.
- **Tagline:** Every claim, checked.
- **Promise:** We show you what a filter is *certified* to do, what it costs to own, and whether it matches your water. No fear, no hype.
- **Name status:** a web search on 2026-11-26 found no water-filter brand by this name. That's **not** a trademark clearance: run a USPTO search before buying the domain (PENDING_APPROVALS.md #1).

## Voice
- Calm, precise, plain English. Write like a good pharmacist explaining a label.
- Lead with the reader's question, then the verdict, then the evidence.
- Use "certified to reduce", never "removes 99.9% of toxins" unless that exact claim is in a certifier listing.
- No fear words: "toxic sludge", "poison", "they don't want you to know".
- Contractions are fine. Skip exclamation points, apart from rare wins.

### Claim language rules (non-negotiable)
| Situation | Say | Never say |
|---|---|---|
| Product is on an NSF/WQA/IAPMO listing for contaminant X | "Certified to NSF/ANSI 53 for lead reduction ([listing])" | "Removes lead" |
| Manufacturer cites third-party lab data only | "Lab-tested by [lab] per the manufacturer; not certified" | "Certified" |
| No evidence | "Marketing claim only (no certification or test data found)" | Anything implying it works |
| Health | "EPA sets a limit of X for Y" (cite EPA) | "Prevents cancer / improves health" |
| Our process | "We reviewed the certification listings and specs" | "We tested", "In our tests", "I've used" |

## Visual identity
| Token | Hex | Use |
|---|---|---|
| Ink | `#0F2A3D` | Text, header |
| Ledger Blue | `#1F6FB2` | Links, primary buttons |
| Clear | `#E8F3FA` | Section backgrounds |
| Verified Green | `#1E8A5A` | "Certified" badges |
| Caution Amber | `#B7791F` | "Lab-tested, not certified" |
| Claim Red | `#B42318` | "Marketing claim only" |
| Paper | `#FAFAF7` | Page background |

- **Type:** Inter for UI and body text (or the system font stack), Source Serif 4 for headlines. Both free under the OFL.
- **Logo:** wordmark "Filter Ledger" with a droplet whose inside is ruled like ledger lines (SVG in `public/logo.svg`).
- **Badges:** CERTIFIED (green), LAB-TESTED (amber), CLAIM ONLY (red). These are always text plus color, never color alone (accessibility).
- **Photography:** clean kitchens, natural light, real-looking sinks. Never use stock "dirty water" shock imagery.

## Disclosure standard
- Site: a one-line disclosure above the first affiliate link on every page ("We earn a commission if you buy through links on this page. It doesn't change our verdicts. How we make money →").
- Social: "#ad · Affiliate link" in the first line of any post that contains a link, plus Meta's branded content or affiliate tools where they apply.
- AI: "Wren is an AI-generated host" in the Page bio, the About page, and video end cards.
